# AsusH3BatteryMonitor

Experimental open-source turbo vibe coded battery monitor for the ASUS TUF Gaming H3 Wireless headset.

The project reads battery data directly from the headset dongle using a reverse-engineered HID protocol.

Current version:

- v0.0.1

For more in depth  etails, usage, limitations, measured battery data, etc.. check out:

[AsusH3BatteryMonitor v0.0.1 README](versions/AsusH3BatteryMonitor_v0.0.1/README.md)

## Status

The battery reader is functional on Windows.

Battery percentage mapping is currently approximate, and charging-state handling is still experimental.
